# 🍔 Delicious Food Website

Welcome to the **Delicious Food Website** project.

This website is a simple multi-page food website created using **HTML** and hosted using **GitHub Pages**.  
It allows visitors to explore different categories of delicious items including **foods, drinks, and desserts**.

The purpose of this project is to create a **simple but attractive website** where users can easily navigate between pages and view different types of food items along with images and descriptions.
